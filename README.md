# 🪔 GANESHA: THE DIVINE QUEST

> *"Complete the sacred journey. Restore the festival of light."*

A commercial-quality 3D Indian festival adventure game created for Ganesh Chaturthi celebrations, built with **Three.js**, **WebGL**, and the **Web Audio API**.

---

## 🌟 Game Highlights

- **Aesthetic**: Modern Indian festival fantasy with warm golden evening lighting, soft shadows, marigold garlands, intricate rangolis, brass diyas, and celebratory 3D particles.
- **Atmospheric Audio**: 100% self-contained procedural synthesizer running on the Web Audio API — featuring Tanpura drone, Bansuri flute melodies in Raga Bhoopali, Dholak/Mridangam festival percussion, and resonant physical acoustic bronze temple bells.
- **Respectful Cultural Design**: Lord Ganesha acts as the divine guide, protector, and source of blessings.
- **Controls & Cross-Platform Support**:
  - **Desktop**: Full keyboard (`WASD`, `Space`, `Shift`, `E`, `Q`, `ESC`) + mouse orbit camera.
  - **Mobile / Tablet**: Responsive virtual touch joystick and action buttons (`JUMP`, `INTERACT`, `ABILITY`).

---

## 🗺️ The 4 Sacred Festival Zones

1. **Festival Street**: Traditional Indian houses with terracotta tile roofs, carved wooden jharokha balconies, hanging marigold garlands, festive sweet & flower stalls, rangolis, and curbside glowing diyas.
2. **Temple Courtyard**: Sandstone mandapa pillars, ceremonial hanging bells, stepped stone platforms, central lotus reflection pond, and the **Rangoli Mandala Puzzle**.
3. **Sacred Garden**: Ancient banyan grove, champak trees, lotus pond, stepping stones, rotating lotus platforms, fireflies, and the **Sacred Temple Bell Sequence Puzzle**.
4. **Festival Stage (Pandal)**: Royal illuminated pandal with golden archway, the **5 Sacred Standing Diyas Puzzle**, the elevated **Lord Ganesha Shrine**, and the central **Divine Festival Flame Altar**.

---

## 🕹️ Puzzles & Gameplay Mechanics

- **20 Collectible Blessings**:
  1. *Modak of Wisdom*
  2. *Lotus of Purity*
  3. *Golden Bell*
  4. *Sacred Diya*
  5. *Festival Flower*
- **"Vighnaharta Blessing" Divine Ability (`Q`)**:
  - 8-second temporary surge with 20-second cooldown.
  - 50% movement speed boost, obstacle slowdown, glowing golden particle trail, and radar highlight of nearby blessings.
- **3 Interactive Puzzles**:
  - **Puzzle 1 (Rangoli Mandala)**: 3 concentric rings aligned to match the sacred top flame marker.
  - **Puzzle 2 (Temple Bells)**: 4 sacred chime bells struck in mantra order (*Om → Lotus → Trishul → Swastika*).
  - **Puzzle 3 (5 Sacred Diyas)**: Ceremonial lighting of the 5 tall brass standing lamps around the stage.
- **Spectacular Festival Climax**:
  - Restoring the Divine Flame triggers an explosion of golden light, continuous 3D fireworks across the night sky, a swirling blizzard of marigold petals, Lord Ganesha's *Abhaya Mudra* blessing gesture, celebratory dhol crescendo, and the chant *"Ganpati Bappa Morya!"*.

## 🚀 Getting Started

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Installation & Run

```bash
# Clone the repository
git clone https://github.com/Jayavardhan137/Ganesh-Devine-Game.git

# Navigate to directory
cd Ganesh-Devine-Game

# Install dependencies
npm install

# Start the local development server
npm run dev
```

Open your browser and navigate to `http://localhost:5173/`.

### Production Build

```bash
npm run build
```

The output bundle will be generated in `dist/`.
